# PUP Vicinity Map

This mini-project presents an interactive vicinity map of the Polytechnic University of the Philippines (PUP), designed to help visitors, students, and guests navigate and explore the campus with ease. The map reflects the university's current layout, including facilities that are still under construction, giving users an up-to-date view of the school grounds.

Using an image map with defined area coordinates, the website allows users to hover over specific sections of the campus map to instantly view relevant facility information alongside a corresponding image — creating a simple but informative browsing experience without needing to navigate away from the map itself.

## About

Navigating a large university campus for the first time can be overwhelming, especially for new students, transferees, or visitors unfamiliar with the grounds. This project aims to make that experience easier by providing a visual, interactive reference that highlights key facilities and their locations at a glance.

## Features

- **Interactive Vicinity Map** — A large, detailed map of the PUP campus occupying the majority of the screen.
- **Hover-to-Reveal Facility Info** — Hovering over a specific building or area on the map instantly displays that facility's name, description, and image on the side panel.
- **Up-to-Date Campus Layout** — Reflects the university's current state, including facilities that are currently under construction.
- **Simple, Guide-Like Experience** — Designed to function as an easy-to-use reference for visitors exploring the campus for the first time.

## How It Works

The map image uses HTML area coordinates to define hoverable zones over each facility. When a user hovers over a defined area, JavaScript detects the interaction and updates the display panel with the corresponding facility's image and details — allowing for quick, seamless exploration of the entire campus without reloading the page.

## Note

This project is optimized for desktop and larger screens, since it relies on hover interactions that are best supported by mouse-based navigation.
